# Project SparkUp 🚀  

## Overview  
**Project SparkUp** is a unique offline matchmaking experience powered by AI, designed to help people connect meaningfully in a structured and engaging environment. By analyzing personality traits and incorporating the Big Five model, SparkUp ensures thoughtful pairings and fosters authentic interactions.  

## Key Features  
- **Personality-Based Matching**: Matches are made using advanced algorithms to evaluate Big Five personality traits.  
- **Quick Dates**: Enjoy structured 5-minute interactions with matches, facilitated through QR code-based table timers.  
- **Feedback-Driven AI**: Initial and final feedback from users is used to refine and improve the matching algorithm.  
- **Dynamic Event Management**: Real-time updates on upcoming matches, table assignments, and personalized schedules.  
- **Seamless User Experience**: OTP-based registration, cached data for easy access, and a user-friendly dashboard.  

## Tech Stack  
### **Frontend**  
- HTML, CSS, JavaScript
- User-focused design with dynamic loaders and an intuitive interface  
- Questionnaire for personality assessment  

### **Backend**  
- PHP with Google App Scripts for database integration
- SQL Databases for Data management
- Google Sheets API for storing and managing user data  
- OTP-based email verification using PHPMailer  
- Logic for table timer, partner details retrieval, and feedback collection
- Jupyter Notebook

### **Algorithm**  
- Proposed **Euclidean Distance** for personality-based matching  
- Incorporates a mix of similarity-based and randomized matches (4 similar + 1 random)  

## How It Works  
1. **Registration**: Users sign up with basic details, complete a personality test, and verify their email via OTP.  
2. **Matching**: AI analyzes user data to provide five curated matches, personalized for each participant.  
3. **Event Interaction**: Matches meet at designated tables, scanning QR codes to start timed interactions.  
4. **Feedback**: Participants provide immediate and final impressions to improve AI performance.  
5. **Results & Insights**: Feedback data helps refine matches and enhances future iterations of Project SparkUp.
