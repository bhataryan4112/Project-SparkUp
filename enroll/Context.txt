Context:
Project SparkUp is an AI-powered matchmaking system designed to enhance real-world social interactions through structured, event-based pairing. It blends psychological principles, machine learning, and interactive event management to provide meaningful social experiences in an offline setting.

The Problem:
Traditional matchmaking or networking systems often rely on swiping-based algorithms (Tinder, Bumble, etc.) or random seat assignments, which fail to create deep, meaningful interactions. Online algorithms struggle to translate into real-life chemistry, and random social events lack structure, often leading to awkward or unproductive interactions.

Project SparkUp’s Approach:

A structured, AI-driven offline event where users register, complete a personality questionnaire, and are matched using AI.
Uses the Big Five Personality Traits (Openness, Conscientiousness, Extraversion, Agreeableness, Neuroticism) as the foundation for pairing.
Ensures 4 out of 5 matches are highly compatible, while 1 match is intentionally randomized to introduce diversity.
A QR-based check-in system at tables ensures the event runs smoothly, with a 5-minute structured interaction per match.
Users provide real-time and final feedback to improve future matches and train the AI further.
Project Development Stages & Key Milestones:

Questionnaire Prototyping & Initial Testing
Developed a 20-question test based on Big Five Personality Traits.
Created a dark-themed website for user-friendly data collection.
Included OTP-based email verification for authenticity.
Matching Algorithm Evolution (Failures & Improvements)
Initial Approach: Euclidean Distance → FAILED ❌
Issue: Did not work well with high-dimensional personality data. Distances were inaccurate, leading to poor matches.
Second Attempt: Cosine Similarity → IMPROVED ✅
Better than Euclidean Distance, as it measured directional similarity, but it often resulted in 95%+ match similarity for almost every participant.
Final Improvement: AI-Powered Pairing → OPTIMAL SOLUTION 🚀
Integrated pre-trained AI models (e.g., OpenAI, Google BERT-based NLP models) for deeper personality profiling.
This allowed fine-tuned matchmaking by analyzing participant responses and behavioral indicators.
Alpha Testing & AI Model Refinement
Conducted Alpha Testing with 50 participants to validate pairing accuracy.
Data collected was used to improve AI prediction models, shifting towards a hybrid recommendation system.
Event Management System & API Integration
Implemented a QR-based table assignment system.
Built APIs for real-time match scheduling and secure data storage using Google Sheets API & Firebase.
Added cache-based session handling to prevent data loss on refresh.
Enhanced Data Privacy & Security Measures
End-to-end encryption for user data.
Email OTP verification to prevent spam registrations.
Strict data anonymization to ensure compliance with privacy standards.
Beta Version Development & Future Enhancements
Current Focus: API Testing for seamless beta launch next month.
Planned Features:
A reinforcement learning-based matchmaking system for adaptive pairings.
Real-time sentiment analysis using NLP models to adjust matches dynamically.
Gamified experience (e.g., achievement badges for social interactions).
Key Technical Components of Project SparkUp:

Frontend:
HTML, CSS, JavaScript, optimized for a dark-themed, interactive user experience.
Registration system with OTP verification.
Live dashboard showing upcoming matches, table assignments, and real-time updates.
Backend & APIs:
Google Sheets API → Used for storing personality test data.
Firebase Authentication → Used for secure login & session management.
PHP Backend with Google Apps Script → Handles matchmaking & user storage.
Custom Matching Algorithm API → Runs AI-based personality matching.
AI Matching Model:
Originally relied on Cosine Similarity, later upgraded to pre-trained AI-based matching.
AI learns from event feedback & user engagement patterns to improve recommendations.
Uses Hybrid Recommendation System (Similarity-based + Controlled Randomization).
QR-Based Interaction System:
Every assigned table has a QR code; users scan to start their 5-minute session.
Timer-based control system ensures structured engagement.
Post-interaction feedback system to rate experience.
Summary:

Project SparkUp is NOT a dating app but a real-world AI-driven social experience.
Initial matchmaking failures led to major algorithmic upgrades, transitioning from basic similarity measures to advanced AI-based pairing.
The event structure is fully automated with QR-based interactions and dynamic user feedback integration.
Security & privacy remain top priorities, ensuring ethical AI-based matchmaking.
Next Phase: Testing API integrations for Beta Release and final AI model fine-tuning for Version 1.0 launch.
